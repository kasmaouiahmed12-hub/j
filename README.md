# Arena FPS 3D

Jeu FPS 3D sans serveur ni installation.

## Publier gratuitement avec GitHub Pages
1. Crée un dépôt GitHub.
2. Envoie `index.html`, `style.css` et `game.js` à la racine.
3. Dans Settings → Pages, choisis la branche principale et le dossier `/root`.
4. GitHub donnera une adresse publique pour jouer.

## Contrôles
- ZQSD / WASD : déplacement
- Souris : viser
- Clic : tirer
- R : recharger
